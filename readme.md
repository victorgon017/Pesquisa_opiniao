## 📊Pesquisa de opinião 

## 📌Objetivo do programa 
O programa tem como objetivo calcular a quantidade de opiniões positivas e negativas dos usuários com base em três opções: Excelente, bom e ruim. E entregar a quantidade de avaliações excelentes e ruins. 

## ⌨️Linguagem de programação utilizada no programa
A linguagem utilizada durante o desenvolvimento do programa foi o Python.

## 👨‍💻Execução do programa 

### 📋Pré-requisito
O pré-requisito para a execução do programa é o **Python 3** instalado na máquina.

### ⚙️Passo a passo 
O usuário deve inserir:
- O seu nome
- A sua idade 
- selecionar entre: 1. excelente, 2. bom e 3. ruim.
Esse processo se repete 50 vezes. Ao final, o programa exibe a quantidade total de avaliações **Excelentes** e **Ruins** para o usuário.
